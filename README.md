# Ashbound

Тёмное фэнтези, roguelike авто-баттлер с **merge-оружием** и idle-прогрессом между забегами.
Игрок только двигается — всё оружие бьёт само; между собой одинаковые предметы сливаются в апгрейды;
между забегами копится постоянная валюта на мета-улучшения.

- **Движок:** Godot 4.3+ (GL Compatibility рендер — работает на слабом железе и мобилках)
- **Жанр:** roguelike auto-battler / bullet heaven (в духе Vampire Survivors, Brotato) + merge-механика + idle-мета
- **Стиль:** pixel-art, dark fantasy

## Структура проекта

```
ashbound/
  scenes/     — .tscn сцены
  scripts/    — .gd скрипты
  assets/
    art/      — спрайты, тайлсеты
    audio/    — музыка, SFX
```

## Запуск

Открыть папку проекта в Godot 4.3 или новее → Play.
